DayPilot — Server

This is a minimal Node + Express TypeScript server scaffold that uses SQLite as a simple datastore.

Getting started:

1. cd server
2. npm install
3. Copy .env.example to .env and adjust values if needed
4. npm run dev

API endpoints (placeholders):
- GET /api/health
- GET /api/tasks
- POST /api/tasks

The server will create the database file and tables on startup if needed.
