DayPilot — Client (Vite + React + TypeScript)

This is a lightweight prototype scaffold that uses the Tailwind CDN for quick styling.

To run locally:

1. cd client
2. npm install
3. npm run dev

Notes:
- This scaffold uses the Tailwind CDN (via <script src="https://cdn.tailwindcss.com"></script>) for rapid prototyping. For production please configure Tailwind in the build pipeline.
- Lucide icons and AI assistant placeholders will be added as components in future iterations.
